# BRAIN CLASSIFICATION :  Semantic Segmentation  of a Rat brain 

Implemented the DINO-v2 model, achieving 99% accuracy and 98% mean IoU for multi-class segmentation. Developed models in PyTorch with 2-D convolutional layers and a linear classifier used as decoders, achieving low loss values of 0.002. Analyzed over 10 research papers to enhance model development and implemented a framework for fine-tuning, integrating both binary and multi-class segmentation approaches. Further improved accuracy across 10 anatomical regions using AdamW optimizer and Optuna for hyperparameter optimization.
