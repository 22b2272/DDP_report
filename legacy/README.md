# Archived Colab exports

These files are preserved as historical experiment records. They are not part
of the supported training pipeline and are not runnable as ordinary Python
scripts: they contain notebook shell commands, Google Colab imports, hardcoded
paths, and inconsistent data/model variants.

Use the maintained `src/neurolens` package and the commands in the root README
instead. Do not run the archived exports; in particular, the original cropping
export contained an operation that deleted a Google Drive directory, which has
been removed from this archived copy.
